# Security Policy

This repository is a curated index. It does not audit, sandbox, operate, or endorse the projects it links to.

## Using listed resources safely

- Review the source code, documentation, permissions, and dependencies of every skill, plugin, MCP server, and integration before installing it.
- Use separate credentials and least-privilege accounts where possible.
- Start with read-only access and test in an isolated workspace or host.
- Never paste API keys, tokens, passwords, or private data into issues or pull requests.
- Follow the official [OpenClaw security guide](https://docs.openclaw.ai/gateway/security) and [security policy](https://github.com/openclaw/openclaw/blob/main/SECURITY.md).

## Reporting a problem

Report a vulnerability to the upstream project that owns the affected code. For OpenClaw core, use a private [GitHub Security Advisory](https://github.com/openclaw/openclaw/security/advisories/new) or the contact path documented in the [OpenClaw security policy](https://github.com/openclaw/openclaw/blob/main/SECURITY.md). Do not disclose an unpatched vulnerability in this repository's public issues or pull requests.

For problems with this list itself, open a public issue without including secrets or exploit details.
